paqu is short for *paqucha*, Quechua for alpaca. It seemed like the right mascot: alpacas are calm, mildly stubborn, and built for thin air and long distances. We're a small herd, working remotely, building tools for modern data collection across web and mobile.

Everything we make comes back to one problem. Forms are how a lot of real-world data gets collected, yet their logic often ends up hardcoded into applications, painful to change and difficult to reuse. We think a form should be **described as data, not rewritten as code** every time a question changes.

## What we make

* 🔧 [**form0**](https://form0.dev) — an open-source, schema-driven form engine for building dynamic data-collection applications across web and mobile.
* 📋 [**reform**](https://reformapp.io) — an offline-first data-collection platform built on form0 for teams working in the field.

## How the two fit together
form0 is **MIT-licensed and free**. It provides the core form logic and can be used independently in your own applications.

reform builds on form0 with the hosted infrastructure and interfaces needed to create, deploy and manage data-collection workflows without having to build the surrounding platform yourself.

## How we work
* **Small on purpose.** Whoever answers support also writes the code.
* **Open by default.** The engine is public, the roadmap is public, and the issues are where the real conversation happens.
* **Built for real-world data collection.** Web, mobile and unreliable connectivity are part of the problem from the beginning, not something added later.
